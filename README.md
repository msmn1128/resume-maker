# 履歴書メーカー

ブラウザだけで動く、履歴書PDF作成ツールです。

- 入力内容は利用者の端末のブラウザ（localStorage）にのみ保存されます
- サーバーへの送信は行いません（CSPで外部通信を禁止）
- PDF出力はブラウザの印刷機能（「PDFに保存」）を使います

## 構成

`index.html` と `fonts/`（外部ライブラリ・外部通信なし）

## フォント

IPAex明朝（JIS X 0208の範囲に軽量化）を `fonts/` に同梱しています。
ライセンスは `fonts/IPA_Font_License_Agreement_v1.0.txt` を参照してください。

## 郵便番号データ

`data/zipdata.txt` は日本郵便の「郵便番号データ（utf_ken_all）」から、郵便番号→住所（都道府県・市区町村・町域）だけを取り出して軽量化したものです。
入力した郵便番号はこの同梱ファイルを引くだけで、外部には送信されません（アプリ自身のファイルを読み込む通信のみ許可）。
